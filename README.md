# live-coding-sprint2

## 🎯 Objectif

Rendre une liste vivante avec le DOM : afficher la classe depuis un tableau, faire l'appel d'un clic, ajouter un apprenant et ne rien perdre au rechargement.

## 🧰 Travail à faire

- Problème déclencheur : « Je clique sur Absent… rien ne se passe. Comment faire l'appel avec cette page ? »
- Afficher la liste depuis un tableau et le compteur des présents (querySelector, createElement, textContent)
- Faire l'appel avec un seul écouteur sur la liste (addEventListener, closest, dataset)
- Ajouter un apprenant par un formulaire vérifié (submit, preventDefault, regex)
- Garder l'appel au rechargement (localStorage, JSON) ; si le temps le permet : nouvelle journée (date, map)

## 📌 Consignes

- Question de sortie : pourquoi un seul écouteur suffit-il, même pour un apprenant ajouté après coup ?
- Trace : code poussé sur le dépôt live-coding-sprint2, un commit par étape ; chacun note une phrase à appliquer à son brief
